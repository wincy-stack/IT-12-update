## Free deployment (Render + Neon)

This project includes a Render Docker deployment. The web service uses Render's free plan and Neon Free for PostgreSQL; both have usage limits, and a free Render service sleeps after 15 minutes without traffic. Its local filesystem is temporary, so application data must stay in PostgreSQL.

1. Push this project to a GitHub repository. Do not commit `.env` or credentials.
2. Create a free PostgreSQL project on [Neon](https://neon.tech/). Copy its connection string and ensure it includes `sslmode=require`.
3. In [Render](https://render.com/), create a Blueprint from the repository containing `render.yaml`. If this project is inside a subfolder, set that folder as the Render root directory.
4. When prompted, set `DB_URL` to the Neon connection string. Render generates the Laravel app key and initial admin/staff passwords.
5. Deploy. The container runs migrations and seeds the starter data on startup. Read the generated `INITIAL_ADMIN_PASSWORD` and `INITIAL_STAFF_PASSWORD` from the Render environment settings and use them to sign in as `admin@gmail.com` and `staff@gmail.com`.

The generated passwords are only used when those accounts are first created; changing the Render variables later does not reset existing account passwords. Keep the generated values private and change the passwords after first login. Don't use this free setup for production or important data: free services may sleep or restart, and free database/provider limits can change.

# About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.
